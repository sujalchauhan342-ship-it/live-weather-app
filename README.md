# 🌤️ Live Weather App

A responsive weather application built using HTML, CSS, and JavaScript. It fetches live weather information for any city using the OpenWeather API.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Current temperature
- 🤗 Feels-like temperature
- 💧 Humidity
- 💨 Wind speed
- 🌡️ Atmospheric pressure
- 👁️ Visibility
- ☁️ Cloud percentage
- 🌤️ Dynamic weather icons
- ❌ Error handling for invalid cities
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## ⚙️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `script.js`.
4. Add your OpenWeather API key:

```javascript
const API_KEY = "YOUR_API_KEY";
```

5. Save the file.
6. Open `index.html` using Live Server.
7. Search for any city to view its current weather.

## 🔑 API

This project uses the OpenWeather Current Weather API to fetch live weather data.

> Never upload your real API key publicly to GitHub.
